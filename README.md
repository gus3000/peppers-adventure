# Pepper's adventure
A small metroidvania that tells the tale of Pepper, that went on an adventure and will come back when he's done having fun !

# Build the project
Clone this project.
```shell
git clone --recursive git@github.com:gus3000/peppers-adventure.git
cd peppers-adventure
```

The addons are all stored as submodules, so if you already cloned the project without the `--recursive` flag, you need to initialize them :
```shell
git submodule update --init --recursive
```

Then launch Godot, import the project and you're good to go !
